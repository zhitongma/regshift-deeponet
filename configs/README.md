# Experiment configurations

`revision/` contains 43 YAML files from the final local code package, grouped by experiment. The final model/scenario mapping is documented in [REPRODUCING.md](../docs/REPRODUCING.md#final-benchmark-configurations).

`revision/base/boost_A4_shift.yaml` is a model fragment; use the full E0/E1 scenario configuration files with the launcher. Coordinate bounds belong under `model.shift_deeponet`.
