# Final manuscript plotting

Run `python scripts/reproduce_figures.py` from the repository root. See [the figure index](../docs/FIGURES.md). All default inputs are included under `../data/`; full simulation fields and checkpoints are unnecessary for drawing. Individual Python plot scripts accept `--output-dir`; the corrected-field script also takes `--data-dir`.

`diagrams/` contains the final TikZ sources for Fig. 1d and 2.
